# TinyCast

Personal native macOS launcher + notch app. macOS 14+, Apple Silicon, Swift 6 / SwiftUI / AppKit.

Requirements: Xcode 16+, [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).

```sh
xcodegen generate && open TinyCast.xcodeproj
```

See `AGENTS.md` for build commands and project rules.
